# SIMULATED -- not study data

Synthetic participants generated by `src/analysis/simulate_participants.py`,
driven through the real app code (`interface.app.Session`) to test the
analysis pipeline. No human produced any row in these files.

* `sim_effect.sqlite3` -- planted effects (H1 +0.20 WoA, H2 trust divergence,
  H3 -0.15 WoA after propagating vs absorbed errors).
* `sim_null.sqlite3` -- no behavioural effects.

Both contain participants built to trip each exclusion criterion.
Every participant also carries a `simulated_participant` event.
